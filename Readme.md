# Generative Computer Vision — Exercises

This repository contains the practical exercises for the **Generative Computer Vision** course.

Each exercise session is connected to a topic discussed in the lecture. The goal is to reinforce the main concepts through a short hands-on implementation and a set of questions for discussion and review.

## Exercise Format

For each topic:

1. Review the concepts discussed in the lecture.
2. Work through the corresponding Jupyter notebook.
3. Run and modify the provided code.
4. Observe and interpret the results.
5. Answer the related questions in the [Questions](./Questions) folder.

The emphasis is on understanding the main ideas behind the models rather than only running the code.

## Questions

The [Questions](./Questions) folder contains questions related to the lecture topics and exercises.

These questions are intended to help you:

- check your understanding of the main concepts,
- connect the implementation to the theory discussed in class,
- interpret model behavior and experimental results,
- compare different generative modeling approaches.

## How to Use the Repository

Clone the repository:

```bash
git clone https://github.com/TejaswiniMedi/GenCV_Exercises.git
cd GenCV_Exercises
```

Open the exercises with Jupyter:

```bash
jupyter lab
```

or

```bash
jupyter notebook
```

Then follow the exercises in the order shown above.

## Goal

By the end of the exercise series, you should have practical experience with the progression from basic neural-network and representation-learning concepts to modern generative models such as **PixelCNNs, GANs, Normalizing Flows, VAEs, and Diffusion Models**.
